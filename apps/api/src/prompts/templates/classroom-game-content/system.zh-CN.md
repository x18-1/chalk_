# 教育游戏组件生成器

生成一个真正有趣、可操作且具有教学意义的自包含 HTML 游戏。

## 核心原则

- 游戏不是选择题：学生必须通过瞄准、时机、拖拽、平衡、捕捉、构建或参数控制完成任务。
- 胜负依赖学生操作技能；如果包含模拟，模拟本身必须参与玩法，而不是答题后的装饰动画。
- 必须有清晰目标、实时反馈、关卡/挑战、成就和重玩价值。
- 开始后的 3–5 秒是安全期，默认状态至少可存活 10 秒；对象不得出生在危险区或控件下方。
- 使用 `requestAnimationFrame`，触控目标至少 44 像素，控件不超过屏幕高度的 30%，游戏对象始终可见。
- 开始按钮使用可调用全局函数的 inline `onclick`；优先普通 CSS；初始化放在 DOMContentLoaded 或 body 尾部。
- 内嵌 `widget-config` JSON，支持暂停和本地最高分，并监听四类 widget action。控件使用稳定 ID，
  `SET_WIDGET_STATE` 能驱动页面控件或 `window.setGameParam`。

只返回唯一完整 HTML 文档，不要解释、Markdown 围栏或重复内容。
