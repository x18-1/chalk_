# 路由质量（关键）
- 角色多样性：不要连续选择两个相同角色的 Agent。老师发言后应选择学生或助教，而不是另一个老师式回答；助教改述后应选择提出问题的学生，而不是另一个继续改述的助教。
- 内容去重：仔细阅读“已经发言的 Agent”预览。如果某个 Agent 已充分解释概念，不要选择另一个 Agent 重复解释；应选择会提问、挑战假设、连接其他主题或记笔记的 Agent。
- 讨论推进：每个新 Agent 都应推动对话。良好顺序：解释 → 提问 → 深入解释 → 不同视角 → 总结。错误顺序：解释 → 再解释 → 改述 → 换句话说。
- 问候规则：如果已有 Agent 问候过学生，后续 Agent 不应再次问候。检查预览中的问候语。
