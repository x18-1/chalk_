# AI 小学生课外辅导教材知识库功能开发需求

我们还需要做一个“教材知识库”功能，用来支持小学一到六年级的课内知识检索、预习和答疑。

这个功能和 Memory 不一样：

- Memory 记的是“这个学生的学习特点”。
- 教材知识库记的是“小学一到六年级教材里的知识内容”。

## 一、核心目标

1. 把小学一到六年级教材导入系统。
2. 按年级、学科、教材版本、单元、课时、知识点进行结构化整理。
3. 学生预习某一课时前，AI 可以从教材知识库中读取对应内容。
4. 学生提问时，AI 可以检索相关教材内容，再基于教材回答。
5. 回答时尽量贴合课本体系，不随便超纲。

## 二、第一版要做的 5 件事

### 1. 教材导入

支持导入小学一到六年级教材内容。

每份教材需要标记：

- 年级
- 学科
- 教材版本
- 上册/下册
- 单元
- 课时
- 标题
- 正文内容
- 图片/例题/练习，如果第一版能处理的话

### 2. 教材内容切分

导入后，需要把教材切成适合检索的小片段。

每个片段建议包含：

- chunk_id
- 年级
- 学科
- 教材版本
- 册别
- 单元
- 课时
- 知识点标签
- 原文内容
- 来源页码
- 向量 embedding

切分原则：

- 不要按固定字数粗暴切。
- 尽量按课时、自然段、例题、知识点切。
- 每个片段要保留来源信息，方便追溯。

### 3. 知识点结构化

除了原文片段，还需要抽取知识点。

例如数学教材里可以抽取：

- 知识点名称：平均分
- 所属年级：三年级
- 所属单元：除法应用题
- 前置知识：乘法口诀、除法含义
- 常见错误：直接猜答案、混淆总数和份数
- 讲解方式：画图、分组、列式

这样后面 AI 不只是“搜原文”，还可以知道这个知识点在教材体系里的位置。

### 4. 预习功能

学生选择某个年级、学科、单元或课时后，AI 从教材知识库读取对应内容，生成预习引导。

预习内容可以包括：

- 这节课要学什么
- 需要先知道哪些旧知识
- 关键概念
- 课本例题讲解
- 2-3 个简单练习
- 学生不懂时可以继续追问

预习时不要直接做成大段讲义，要更像老师带着学生一步步看。

### 5. 问答检索

学生问问题时，系统先判断问题属于哪个学科/年级/知识点，再从教材知识库检索相关内容，放进 AI 提示词。

检索优先级：

- 当前学生年级
- 当前教材版本
- 当前学习单元
- 问题相关知识点
- 前置知识点
- 相邻课时内容

AI 回答时要基于检索到的教材内容，不要随便编教材里没有的内容。

## 三、建议的数据结构

### 1. textbooks

保存教材基本信息：

- textbook_id
- subject
- grade
- version
- semester
- title
- source_file
- created_at

### 2. textbook_chunks

保存教材切分后的片段：

- chunk_id
- textbook_id
- subject
- grade
- version
- semester
- unit
- lesson
- page
- content
- embedding
- metadata

### 3. knowledge_points

保存知识点结构：

- knowledge_point_id
- name
- subject
- grade
- version
- unit
- lesson
- description
- prerequisites
- common_mistakes
- teaching_tips
- related_chunk_ids

### 4. preview_sessions

保存学生预习记录：

- preview_id
- student_id
- subject
- grade
- unit
- lesson
- used_chunk_ids
- summary
- created_at

## 四、第一版验收标准

1. 能导入一份教材，并按年级/学科/单元/课时查询。
2. 学生选择某一课时后，AI 能生成预习内容。
3. 学生问教材相关问题时，系统能检索到对应教材片段。
4. AI 回答能引用或依据教材内容，不明显超纲。
5. 每次回答最好能追溯到教材来源，例如课本、单元、页码。
6. 检索不到内容时，AI 要说明不确定，不要强行编。
7. 教材知识库和学生 Memory 要分开存储，但回答时可以一起使用。

## 五、和 Memory 的配合方式

学生问问题时，系统同时读取两类信息：

1. 教材知识库：这个问题应该怎么讲。
2. 学生 Memory：这个学生适合怎么讲。

例如：

教材知识库告诉 AI：

“平均分是把总数分成同样多的几份，可以用除法表示。”

学生 Memory 告诉 AI：

“这个学生做平均分题时容易直接猜答案，更适合先画图理解。”

最终 AI 的回答就应该是：

先按教材讲平均分的概念，再用画图方式引导学生理解，而不是直接给公式。
