# AI 小学生课外辅导 Memory 功能开发需求

我们先做 AI 小学生课外辅导产品的 Memory MVP。

这个功能的目标不是简单保存聊天记录，而是让 AI 能记住学生的学习特点，并在下一次辅导时用起来。

核心闭环是：

学生发生学习行为 -> 系统保存学习记录 -> AI 判断哪些信息值得长期记住 -> 系统保存/更新学生记忆 -> 下次辅导前读取相关记忆 -> AI 根据记忆调整讲解方式。

第一版不做复杂知识图谱，也不做全自动学习路径规划，先把“记住并用起来”跑通。

## 一、产品目标

第一版 Memory 要实现：

1. 记录学生的关键学习行为。
2. 从学习行为中提取值得长期记住的信息。
3. 把这些信息保存为学生长期记忆。
4. 遇到相似记忆时合并更新，不要重复新增。
5. 学生下次学习时，AI 能读取相关记忆并调整教学方式。
6. 系统不能保存敏感信息，也不能给孩子贴负面人格标签。

## 二、第一版要做的 4 个功能

### 1. 记录学习过程

每次学生发生关键学习行为，都保存一条学习记录。

需要记录的行为包括：

- 学生发起一次对话
- 学生提交一道题的答案
- AI 批改一道题
- AI 完成一次讲解
- 学生表示听懂/没听懂
- 老师或家长修改学生信息

每条学习记录建议保存：

- 学生 ID
- 科目
- 行为类型
- 原始内容
- 时间
- 关联题目 ID，如果有的话
- 关联会话 ID，如果有的话

### 2. 从学习记录里提取“值得长期记住的信息”

每次对话或做题结束后，后台调用一次 AI，让它判断这次有没有值得长期记住的信息。

值得记录的例子：

- 学生正在学三年级下册面积单位。
- 学生做平均分应用题时容易直接猜答案。
- 学生更适合用画图方式理解数学题。
- 学生被直接说“错了”时容易沮丧。
- 家长要求 AI 不要直接给答案，要先引导。
- 学生最近连续多次在单位换算题上出错。

不要记录的内容：

- 普通闲聊。
- 一次性的情绪。
- 没有教学价值的信息。
- 账号、密码、手机号、家庭住址等敏感信息。
- “学生很笨”“学生不认真”“学生没有天赋”这类负面人格标签。
- 只根据一次表现就下绝对结论的判断。

提取出的记忆要尽量写成“可用于教学决策”的表达。

不推荐：

- 学生数学不好。
- 学生很粗心。

推荐：

- 学生在平均分应用题中对除法含义掌握不稳定，容易直接猜答案。
- 学生做长题干应用题时容易漏看条件，需要先复述题意再列式。

### 3. 保存和更新学生记忆

把上一步提取出的信息保存到学生的长期记忆里。

保存前要先检查有没有相似记忆：

- 如果是新信息，就新增一条。
- 如果和已有记忆类似，就更新原来的，不要重复新增。
- 如果只是一次证据，不要写得太绝对。
- 如果多次出现同类情况，可以提高可信度。
- 如果新的表现和旧记忆冲突，不要马上删除旧记忆，可以降低旧记忆可信度，或标记需要复核。

每条记忆至少包括：

- 学生 ID
- 记忆类型
- 科目
- 记忆内容
- 可信度
- 重要程度
- 来源记录
- 是否启用
- 创建时间
- 更新时间

记忆类型先用这几类：

- 基础信息：年级、教材、地区、当前章节。
- 兴趣偏好：喜欢足球、恐龙、漫画等，可用于设计例子。
- 学习方式：需要画图、喜欢一步步推导、适合先举例再总结。
- 知识薄弱点：某个知识点掌握不稳定，或某类题反复出错。
- 优势能力：计算速度快、表达清楚、图形理解能力强等。
- 情绪/动力：被直接否定时容易沮丧，连续做错时容易着急。
- 教学规则：家长/老师明确要求的规则，例如不要直接给答案，要先提示。

### 4. 在 AI 辅导前读取相关记忆

学生每次开始新对话或提交新题目时，系统先读取这个学生相关的记忆，然后放进 AI 的提示词里。

读取规则：

- 优先读取当前科目的记忆。
- 优先读取重要程度高的记忆。
- 优先读取最近验证过的记忆。
- 优先读取教学规则和学习方式。
- 一次最多给 AI 5-10 条。
- 不要把所有历史聊天记录都塞进去。

示例：

学生问数学题时，给 AI 的上下文里可以包含：

- 学生是三年级，正在学习除法应用题。
- 学生做平均分题时容易直接猜答案。
- 学生更适合先画图再列式。
- 家长要求不要直接给最终答案，先给提示。
- 如果学生连续两次答错，再给完整讲解。

AI 使用记忆时要自然调整教学方式，不要直接对学生说“我记得你之前总是不会这个”。

不推荐：

- 你之前平均分题老是错，所以这次要认真。

推荐：

- 我们先不急着算答案。可以先把题目里的数量画出来，再看看它要平均分成几份。

## 三、建议的数据结构

可以先用下面 4 类数据。

### 1. 学生基础档案

保存学生相对稳定的基础信息。

字段建议：

- student_id
- name
- grade
- region
- textbook_version
- created_at
- updated_at

### 2. 学习记录

保存每次原始学习行为。

字段建议：

- event_id
- student_id
- session_id
- question_id
- subject
- event_type
- content
- created_at

event_type 可以包括：

- chat
- quiz_submit
- quiz_result
- explanation
- feedback
- profile_edit

content 可以用 JSON 保存原始内容。

### 3. 学生长期记忆

保存可被下次辅导使用的记忆。

字段建议：

- memory_id
- student_id
- memory_type
- subject
- content
- confidence
- importance
- evidence_event_ids
- status
- last_seen_at
- created_at
- updated_at

status 可以包括：

- active：启用
- paused：暂停使用
- deleted：已删除
- needs_review：需要人工复核

### 4. 教学画像

可以从长期记忆中定期生成一个汇总画像，用来更稳定地指导 AI。

字段建议：

- student_id
- profile
- updated_at

profile 可以包括：

- 当前学习阶段
- 主要薄弱点
- 常用教学策略
- 最近需要复习的内容
- 家长/老师规则

## 四、给 AI 的提示词规则

在抽取记忆时，AI 要遵守：

1. 只记录对未来教学有帮助的信息。
2. 不记录敏感信息。
3. 不记录负面人格标签。
4. 不根据一次表现下绝对结论。
5. 尽量把记忆写成具体、可教学使用的描述。
6. 如果证据不足，要降低可信度。
7. 如果没有值得记住的信息，就返回空结果。

在辅导学生时，AI 要遵守：

1. 根据学生记忆调整讲解方式。
2. 如果有知识薄弱点，优先用更基础的解释。
3. 如果有学习方式偏好，按偏好的方式讲。
4. 如果有情绪/动力特点，调整反馈语气。
5. 如果有家长/老师教学规则，必须遵守。
6. 不要生硬暴露记忆内容。
7. 不要说“你之前总是不会”“你很粗心”这类话。

## 五、第一版开发顺序

建议按这个顺序做：

1. 先保存学习记录。
2. 再做 AI 记忆提取。
3. 再做记忆保存和相似合并。
4. 再做辅导前记忆读取。
5. 再修改 AI 辅导提示词，让它使用记忆。
6. 最后做每周学习画像总结。

## 六、第一版验收标准

1. 学生完成一次对话或做题后，后台能生成 0-3 条候选记忆。
2. 如果没有值得记住的信息，系统不会强行生成记忆。
3. 同类记忆不会重复出现很多条，而是合并更新。
4. 学生再次问相关问题时，AI 的讲解方式会根据记忆变化。
5. 系统不会保存账号、密码、手机号、家庭住址等敏感信息。
6. 系统不会保存“学生很笨”“学生不认真”这类负面人格标签。
7. AI 使用记忆时表达自然，不会让学生感觉被贴标签。
8. 每条重要记忆最好能追溯到来源记录。

## 七、几个测试用例

### 测试 1：知识薄弱点

输入：

学生连续两次做平均分应用题出错。

期望：

系统生成或更新一条记忆：

“学生在平均分应用题中对除法含义掌握不稳定，容易直接猜答案。”

下一次：

学生再做类似题时，AI 先引导学生画图或复述题意，而不是直接讲公式。

### 测试 2：学习方式

输入：

学生多次表示“画出来我就懂了”。

期望：

系统生成一条记忆：

“学生更适合通过图示理解数学应用题。”

下一次：

AI 讲数学题时优先用画图、分组、列表等方式解释。

### 测试 3：教学规则

输入：

家长设置：“不要直接告诉答案，先提示。”

期望：

系统生成一条教学规则记忆：

“辅导时不要直接给最终答案，应先给提示，引导学生自己尝试。”

下一次：

AI 必须先提示，不直接给答案。

### 测试 4：不该记的内容

输入：

学生说：“我今天好烦。”

期望：

不写入长期记忆，最多只作为当前会话语气参考。

### 测试 5：避免负面标签

输入：

学生连续做错三道计算题。

不允许生成：

“学生很粗心。”

“学生数学很差。”

可以生成：

“学生在连续计算中容易漏进位，需要分步骤检查计算过程。”

## 八、重点原则

Memory 不是聊天记录存档，而是教学决策系统。

每条记忆都要问：

1. 这条记忆下次教学会怎么用？
2. 它有没有证据？
3. 它会不会对孩子形成不公平标签？

如果这四个问题答不上来，就先不要写入长期记忆。
